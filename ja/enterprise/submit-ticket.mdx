[契約済み：チケットを送信](https://space.langbot.app/profile?tab=tickets&language=ja)

契約に登録した Space アカウントでログインし、プロフィールのチケット画面から企業サポートの問題受付、または企業保障の更新・相談を選んでください。テンプレートはログインユーザーが利用できますが、企業特典は契約、登録アカウント、有効期間の確認後に適用されます。契約番号だけでは本人確認になりません。

## 提供する情報

- 購読・契約番号、企業名、依頼種類、概要。
- 不具合：LangBot バージョン、導入方法、期待結果と実際の結果、再現手順、業務への影響。
- 機密情報を除去したログ抜粋。取得できない場合は理由を記入。トークン、パスワード、会話全文、個人情報、設定ファイル原本を送信しないでください。
- 更新・相談：登録インスタンス、該当する現在版と更新先、相談目的、希望日時。
- 文書・調達資料の質問に架空のログや再現手順は不要です。相談フォームに内容を記入してください。技術相談枠は保障プランの特典です。

フォームはテキストを収集し、インスタンス情報の自動収集や診断パック生成は行いません。画像は必要な匿名化済み画面のみ添付してください。脆弱性の詳細を公開 GitHub issue に投稿しないでください。

## 受付後

契約と範囲を確認してから、文書案内、追加情報の依頼、対象となる相談予約、Core 不具合の確認、または対象外の説明を行います。自動メールは初回有人応答に含みません。

汎用不具合の公開保守には必要な匿名化済み再現情報のみを利用します。契約、顧客ログ、業務情報は GitHub に自動転送しません。同じチケットで情報を追加してください。
