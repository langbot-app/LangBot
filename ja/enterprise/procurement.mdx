## 契約と請求書

契約対象：**LangBot オープンソースソフトウェアの年間保守、バージョン情報および技術サポートサービス**。

契約企業単位の年額料金で、人数課金ではありません。税金、請求書の種類、期間は正式見積と契約で確認します。財務担当が発行可能な区分を確認し、寄付や追加商用ライセンス料として扱いません。海外向け請求、通貨、対応言語は個別に確認します。翻訳ページは日本の税務請求書や日本語の有人対応を保証しません。

## 開始時の提供物

- 注文・契約書、期間、指定担当者。
- 追加ソフトウェア利用許諾ではなくサポート関係を証明する年間購読証明書。
- 版を明記した範囲・応答説明、工単案内、Space アカウント登録。
- 保障プランの本番 1 インスタンス登録と相談枠。
- 別途同意した場合の支援企業一覧への掲載（匿名可）。

四半期の公開保守まとめ、チケット、相談の記録を保存します。保障プランには年次のバージョン・依存関係・安全状態の説明も含みます。後日のページ更新は既存契約の特典を自動変更しません。

更新は別途合意し、自動引き落としは前提としません。開始・終了、解約、返金は契約によります。満了後も Apache 2.0 の利用は制限しません。Cloud 資源、モデル利用枠、ホスティングは別商品です。

最初の連絡では企業名、希望プラン、利用概要をお送りください。請求情報は契約時に非公開の方法で提供し、公開 issue や GitHub に記載しないでください。
