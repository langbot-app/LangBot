## 利用開始までの流れ

1. **お問い合わせ**：[hello@langbot.app](mailto:hello@langbot.app) に企業名、希望プラン、利用状況をお送りください。
2. **見積の確認**：範囲、税金、請求書について確認し、年間サービス契約を締結します。
3. **支払いと登録**：契約に従って支払い、担当者、Space アカウント、サービス期間を登録します。
4. **利用開始**：証明書とサービス説明を受け取ったら、[チケットを送信](/ja/enterprise/submit-ticket)できます。

<Note>
最初のご連絡は企業名、希望プラン、利用概要だけで十分です。請求書用の情報は契約前にご提供ください。銀行・税務情報を公開チケットや GitHub で送らないでください。
</Note>

## 契約と請求書

| 項目 | 内容 |
| --- | --- |
| 契約主体 | LangBot プロジェクトの運営法人（詳細は見積書・契約書でご案内） |
| 契約対象 | LangBot オープンソースソフトウェアの年間保守、リリース情報、技術サポートサービス |
| 料金 | 契約企業単位の年額、人数課金なし |
| 請求書の品目 | 発行可能な範囲で経理が確認（ソフトウェアサービス費、技術サポート費など） |

寄付や商用ソフトウェアライセンス料としての請求書は発行しません。

## 提供物

- サービス期間と担当者を記載したサービス注文書・契約書
- 年次サポート証明書（サポート関係を証明するもので、追加のソフトウェアライセンスではありません）
- 版管理されたサービス範囲の説明、Space チケット窓口とアカウント登録
- 保障プラン：本番インスタンス登録と技術相談枠
- 期間中：四半期の保守まとめ、チケット・相談記録。保障プランは年次のバージョン・依存関係・セキュリティ状態の説明も含みます

支援企業一覧への掲載は別途同意が必要で、匿名も選べます。サービス説明の後日の変更は、締結済み契約の内容を変えません。

## 更新

更新は別途確認し、自動課金はありません。開始、終了、解約、返金は契約によります。

本サービスには LangBot Cloud の計算資源、モデル利用枠、ホスティングは含まれません。期間終了後も Apache 2.0 に基づき LangBot を利用できます。
