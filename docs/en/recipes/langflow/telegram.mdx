This recipe puts your Langflow app behind a Telegram bot. LangBot receives messages from Telegram, runs them through a pipeline, and sends the answer back, so you do not write any platform code.

Langflow builds agents and flows with a drag-and-drop editor. LangBot runs a flow through the Langflow API for every message.

## What you need

- A running LangBot instance: [LangBot Cloud](https://space.langbot.app/cloud) (no server needed) or a [self-hosted deployment](/en/deploy/langbot/docker) with Docker or `uvx langbot`.
- A Langflow account or instance that LangBot can reach over the network.
- A bot token from [@BotFather](https://t.me/BotFather) (send `/newbot` and pick a username ending in `bot`).

## Networking

Telegram uses long polling: LangBot only needs outbound access to `api.telegram.org`. No public webhook URL is required, so a laptop or home server works.

## 1. Prepare Langflow

1. Build a flow in Langflow (the Simple Agent template is a good start).
2. Create an API key under **Settings**.
3. Copy the **Flow ID** from **Share → API access**.

## 2. Create a pipeline

Open **Pipelines** in the LangBot WebUI, create a pipeline (or edit the default one) and set **AI** as follows. If the runner is not listed, install the official runner plugin from **Plugins** or the [LangBot Space marketplace](https://space.langbot.app/market).

| Field | Value |
| --- | --- |
| Runner | **Langflow** (official Langflow Agent runner plugin) |
| Base URL | Your Langflow address, reachable from LangBot |
| API Key | The Langflow API key |
| Flow ID | The flow to run |

## 3. Create the Telegram bot

1. Under **Bots**, create a bot and select the **Telegram** adapter (the new adapter in LangBot 4.11, not the deprecated legacy one).
2. Paste the token, enable Markdown and streaming if you want them, then enable and save the bot.

## 4. Bind and test

Open the bot, select the pipeline you created, save and make sure the bot is enabled.

Press **Start** in a private chat with the bot and send a message. In groups, the message must match the pipeline's trigger rules (for example, mention the bot or reply to it).

## Troubleshooting

- Connection refused: `http://localhost:7860` only works when Langflow runs on the same host and network namespace as LangBot.
- Only one running instance may poll a token. If replies are missing, make sure the same bot is not enabled in another LangBot instance or script.
- Check **Monitoring** in the WebUI: every message, pipeline run and error is recorded there.

## FAQ

### Do I need a server with a public IP for Telegram?

No. Telegram uses long polling: LangBot only needs outbound access to `api.telegram.org`. No public webhook URL is required, so a laptop or home server works.

### Does the Telegram bot support streaming replies?

Yes. Enable streaming on the bot; the AI back end must also stream. See the [platform feature matrix](/en/insight/platform-features) for details.

### Can the same Langflow setup serve other platforms too?

Yes. A pipeline can be bound to many bots, so one configuration can answer on several platforms at once.
