This recipe puts a Claude model behind a Lark (Feishu) bot. LangBot receives messages from Lark (Feishu), runs them through a pipeline, and sends the answer back, so you do not write any platform code.

Use Anthropic's Claude models with LangBot's built-in Agent, including tool use with MCP servers, Skills and the code sandbox.

## What you need

- A running LangBot instance: [LangBot Cloud](https://space.langbot.app/cloud) (no server needed) or a [self-hosted deployment](/en/deploy/langbot/docker) with Docker or `uvx langbot`.
- A Claude account or server you can call from LangBot.
- A Feishu or Lark custom app (`app_id` and `app_secret`). The one-click setup in LangBot can create and authorize it for you.

## Networking

The default WebSocket long connection needs no public IP. Where long connection is unavailable (for example some Lark international setups), webhook mode requires a public HTTPS address; LangBot Cloud includes one.

## 1. Add the Claude model

1. Create an API key in the Anthropic console.
2. In LangBot, open **Models**, add an LLM model with the provider set to Anthropic, then paste the API key and the model ID.
3. Enable **Tool Use** if the model supports function calling; MCP tools, Skills and the sandbox need it.
4. Keep the provider's default request URL unless you use a gateway. Use a current Claude model ID from Anthropic's documentation.

## 2. Create a pipeline

Open **Pipelines** in the LangBot WebUI, create a pipeline (or edit the default one) and set **AI** as follows.

| Field | Value |
| --- | --- |
| Runner | **Local Agent** (built-in Agent) |
| Model | The model you just added. You can add fallback models. |
| Prompt | Instructions: who the bot is, tone, what it must not do. |
| Knowledge Bases | Optional. Attach a knowledge base so answers come from your documents. |

## 3. Create the Lark (Feishu) bot

1. Create a bot with the **Lark** adapter, select the platform domain (Feishu or Lark) and use **One-Click Setup**, or enter `app_id` and `app_secret` manually.
2. Add the message permissions and event subscriptions from the guide (and the card permissions if you want streaming cards), then publish an app version.

## 4. Bind and test

Open the bot, select the pipeline you created, save and make sure the bot is enabled.

Search for the bot in Feishu/Lark, send it a direct message, then add it to a group and mention it.

## Troubleshooting

- The agent never calls tools: enable **Tool Use** on the model.
- No messages arrive: confirm the app version is published and the event subscription uses the same mode (long connection or webhook) as LangBot.
- Check **Monitoring** in the WebUI: every message, pipeline run and error is recorded there.

## FAQ

### Do I need a server with a public IP for Lark (Feishu)?

Not necessarily. The default WebSocket long connection needs no public IP. Where long connection is unavailable (for example some Lark international setups), webhook mode requires a public HTTPS address; LangBot Cloud includes one.

### Does the Lark (Feishu) bot support streaming replies?

Yes. Enable streaming on the bot; the AI back end must also stream. See the [platform feature matrix](/en/insight/platform-features) for details.

### Can the same Claude setup serve other platforms too?

Yes. A pipeline can be bound to many bots, so one configuration can answer on several platforms at once.
