## Installing the Main Program

1. Go to the [Release](https://github.com/langbot-app/LangBot/releases) page to download the latest version of the zip package (recommended) `langbot-xxx-all.zip` (do not download Source Code as it does not include WebUI). Extract it and open a command line (terminal) in the extracted directory.

![Download Release](/images/zh/deploy/langbot/manual/dl_release.png)

2. Install dependencies

We use [uv](https://docs.astral.sh/uv/) to manage dependencies.

```bash
pip install uv
uv sync
```

The default installation does not include the optional vector stores. To use one
of these backends, add its extra to `uv sync` (extras can be combined):

| Backend | extra |
| --- | --- |
| SeekDB vector store / built-in embedding model | `seekdb` |
| Milvus | `milvus` |
| Valkey Search (not on Windows) | `valkey` |

```bash
uv sync --extra seekdb
```

Embedded-mode platform support depends on the available `pylibseekdb` wheels;
Apple Silicon currently requires macOS 15 or later. All other LangBot features
can use the default `uv sync` installation.

### Optional Voice Transcoding Support (SILK / WeChat Native Voice)

If you need native voice bubbles on platforms like WeChat (SILK encoding) or audio transcoding support, install system `ffmpeg` and the `audio` extra:

- **System Dependency**: `ffmpeg` (macOS: `brew install ffmpeg`, Ubuntu/Debian: `sudo apt-get install -y ffmpeg`, Windows: `winget install Gyan.FFmpeg`)
- **Python Extra**:
  ```bash
  uv sync --extra audio
  # or combine with seekdb
  uv sync --extra seekdb --extra audio
  ```

If transcoding dependencies are not installed, LangBot performs **graceful degradation** by delivering the audio as a playable audio file attachment rather than dropping the message.

3. Run the main program once to generate configuration files

```bash
uv run main.py
```

You will see the following message:

```

| |   __ _ _ _  __ _| _ ) ___| |_

📖Documentation: https://langbot.app/docs

The following files do not exist and have been automatically generated. Please modify the configuration files as needed and restart:
- data/config.yaml
...
```

You can now use Ctrl+C to exit the program and continue to the [Configure Bots](/en/usage/platforms/readme) page.
