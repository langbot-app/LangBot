---
title: 工作区 API
description: 在插件中读取和管理 Agent、流水线、机器人、模型、知识库等工作区资源。
---

工作区 API 让插件可以操作它所安装的工作区：列出和修改 Agent 与流水线、查询机器人、管理模型和知识库、读取监控数据等。它开放的操作与 LangBot 的 HTTP API、MCP 服务和工作区助手完全相同，因此成员能通过这些途径完成的事，插件都可以在成员授权的范围内自动完成。

每个操作都有一个稳定的 ID，例如 `pipeline.list` 或 `knowledge.base.retrieve`。插件只能调用自己[在 manifest 中声明](/zh/plugin/dev/permissions#声明权限)、并且已由成员授予该安装的操作。

## 调用操作

在任意组件中通过 `self.plugin.workspace` 调用。每个操作都有一个按 ID 命名、带类型标注的方法：

```python
from langbot_plugin.api.definition.components.tool.tool import Tool


class WorkspaceSummary(Tool):
    async def call(self, params, session, query_id):
        result = await self.plugin.workspace.pipeline.list()
        if not result["ok"]:
            return f"无法获取流水线列表：{result['error']['message']}"

        names = [pipeline["name"] for pipeline in result["result"]]
        return "流水线：" + "、".join(names)
```

方法以关键字参数传参，参数与操作的输入结构一一对应，编辑器里能看到它们的类型和说明。少数名称会被调整为合法的 Python 标识符：如果某一段恰好是 Python 关键字，会在末尾加下划线（例如 `import_`），其他非法字符会替换为下划线。发送时仍使用原始参数名。

如果需要在运行时决定调用哪个操作，可以直接按 ID 调用，效果与类型化方法完全相同：

```python
result = await self.plugin.workspace.call("knowledge.base.retrieve", kb_uuid=kb_uuid, query="退款政策")
```

`await self.plugin.workspace.list()` 返回该安装已获授权的操作及其输入结构，并按 `domains` 分组。可以用它动态生成工具列表，或在提供某项功能前先确认是否已获授权。

### 在运行器中

运行器通过 `ctx.api.workspace` 拿到与本次运行绑定的代理。它提供相同的方法，也由相同的安装授权控制；区别在于 LangBot 会把每次调用记录到当前运行下。

发起本次运行的 Agent 或流水线，可能限定了模型应当看到哪些工作区操作，这个选择通过 `ctx.resources.workspace_operations` 传入。如果运行器要把工作区操作作为工具提供给模型，应当只提供这些操作；列表为空时，一个都不要提供。LangBot 内置的 LocalAgent 就是这样做的。

## 返回结果与错误

工作区调用不会因为业务错误抛出异常，而是始终返回一个字典：

```python
# 成功
{"ok": True, "result": ..., "operation": {"id": "pipeline.list", ...}}

# 失败
{"ok": False, "error": {"code": "permission_denied", "message": "...", "details": {...}}}
```

读取 `result` 之前先检查 `ok`。常见错误码：

| 错误码 | 含义 |
| --- | --- |
| `permission_denied` | 该安装没有获得这个操作的授权，或者安装已停用。`details.denied_operations` 列出缺少的操作 ID。 |
| `invalid_input` | 参数不符合操作的输入结构。 |
| `not_found` | 引用的资源在当前工作区中不存在。 |
| `application_error` | 操作已执行但失败，`message` 中说明原因。 |

权限不足是预料之中的情况，因为成员可能只授予插件所声明权限的一部分。遇到时应说明缺少什么，而不是让整个命令或运行失败。

## 选择要声明的操作

每个操作都有风险等级，成员确认时可以看到：

- **读**：只返回数据，例如 `pipeline.list`、`stats.basic`。
- **写**：修改工作区配置，例如 `pipeline.update`、`knowledge.file.store`。
- **高危**：删除资源、影响 LangBot 之外的对象，或消耗大量资源，例如 `bot.delete`、`pipeline.chat.broadcast`。确认对话框会单独标出这类操作。

授予某个操作的成员，自己必须具备该操作要求的权限（见下表最后一列）。只申请插件真正需要的操作；申请大量高危操作，很可能会被拒绝或被删减。

`knowledge.*` 这类通配符会申请某个前缀下的所有操作，但并不是每个前缀都可以这样用，详见[通配符](/zh/plugin/dev/permissions#通配符)。
