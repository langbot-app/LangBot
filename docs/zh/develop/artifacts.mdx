---
title: "Artifact 文件接口"
description: "通过 HTTP 或 MCP 上传、读取、保留和删除当前主体拥有的文件。"
---

Artifact 为文件提供不透明引用和元信息。账户或 API 密钥只能访问当前工作区内属于自己的文件。知道 ID 不代表获得权限，同一工作区的其他成员也不能凭 ID 读取。

沿用工作区 HTTP 认证。读取需要 `resource.view`；创建、保留、释放和删除需要 `resource.manage`。

| 操作 | HTTP |
| --- | --- |
| 上传 | `POST /api/v1/artifacts`，multipart `file`，可选 `ttl_seconds` |
| 元信息 | `GET /api/v1/artifacts/{id}` |
| 下载 | `GET /api/v1/artifacts/{id}/content`，可选 `max_bytes` |
| 读取结构化内容 | `GET /api/v1/artifacts/{id}/read`，可选 `mode`、`offset`、`max_chars`、`page_start`、`page_end` |
| 持久保留 | `POST /api/v1/artifacts/{id}/retain` |
| 释放保留 | `POST /api/v1/artifacts/{id}/release` |
| 删除 | `DELETE /api/v1/artifacts/{id}` |

上传返回含 `id` 的元信息。下载返回原始字节，使用附件响应及 digest ETag。上传和下载上限为 10 MiB。`max_bytes` 限制整个文件的读取大小，不表示字节范围；超过限制时拒绝读取，不截断文件。

新上传文件默认 24 小时后过期；`ttl_seconds` 可设为 1 秒至 7 天。retain 添加持久保留标记，不改变访问权限。release 移除该标记并恢复 24 小时临时保留期；重复 release 不续期。仍有标记的文件不能删除，需要先释放。过期资产不能读取或重新保留；清理任务回收过期临时内容。

不存在、已删除和无权访问的 ID 均返回 404。已过期的自有文件返回 `artifact_expired`（410），删除仍在使用的文件返回 `artifact_in_use`（409），读取超限返回 `artifact_too_large`（413），完整性校验失败返回 `artifact_integrity_failed`（422）。

删除立即阻止后续访问，底层字节由维护任务回收；已授权的在途下载可能完成，也可能因并发回收而失败。

## MCP

原生 PDF 需要可信的模型能力信息；对于已由供应商确认支持、但能力目录尚未识别的模型别名，可由管理员在模型的现有 `abilities` 字段中声明 `pdf_input`。未声明且能力未知时会明确拒绝原生 PDF，仍可使用文本模式。

内置 `/mcp` 服务提供 `create_artifact`、`get_artifact`、`read_artifact`、`read_artifact_content`、`retain_artifact`、`release_artifact` 和 `delete_artifact`，使用相同的归属及权限检查。创建参数为 `filename`、`content_base64`，以及可选的 `mime_type` 和 `ttl_seconds`。原始读取参数为 `artifact_id` 及可选的 `max_bytes`，返回 base64 和元信息。`read_artifact_content` 沿用 HTTP `/read` 的读取参数，返回原生 MCP 文本、图片或嵌入 PDF 内容，不把 base64 放入普通文本。对应 Workspace 操作为 `artifact.read_content`。

`read_artifact` 传输原始字节。账户资产管理操作仍不开放插件工作区授权、插件类型化方法、默认模型工具或 `lbctl` 命令。原有上传接口和运行内 `file_id` 接口继续使用原契约。

## Agent 按需读取

Runner 初始输入只包含附件引用、名称、MIME 和大小。图片、文件字节和来源 URL 保留在 Host 的运行内注册表中，不直接进入首轮模型消息。当前消息和引用消息中的附件各有独立引用。Agent 需要内容时才调用读取工具，Host 继续检查当前 run 的冻结附件权限；另一个 run 的引用不能授权访问。

`read_input_attachment_content` 返回结构化内容，支持以下模式：

| 模式 | 行为 |
| --- | --- |
| `auto` | 读取 UTF-8 文本、返回结构化图片，或提取 PDF 文本。 |
| `text` | 有界读取字符范围；PDF 结果标明所选页码，明确不包含视觉内容。 |
| `native` | 将图片或 PDF 作为原生输入交给支持的模型；不支持时明确报错。 |
| `pages` | 本阶段尚不支持页面渲染，返回明确错误。 |

文本使用从零开始的 `offset` 和 `max_chars`（默认 8192，最大 16384）。结果带 `truncated` 和 `next_offset`，应从该位置继续读取，不能将截断内容当作全文。PDF 文本使用从一开始的 `page_start` 和可选 `page_end`，每次最多十页，并返回下一页位置；不做 OCR，也不保留图片和页面布局。其他二进制格式明确拒绝，原始文件仍可下载。

Agent 调试 API 的请求可带 `artifact_ids`，最多 20 个不同的自有上传资产 ID。Host 在启动 run 前按真实认证主体检查归属，再给该 run 引用。请求中的事件 `actor` 不会改变资产归属。独立的 Workspace 管理助手本阶段仍不接受附件输入。已有原始字节接口 `read_input_attachment` 继续供有权限的 Runner 代码使用。
