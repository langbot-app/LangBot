---

企业支持订阅聚焦于 **LangBot Core 本身**，通过统一工单提供分诊与指引，而不是代运维或定制开发。

## 包含与不包含

| 包含 | 不包含 |
| --- | --- |
| LangBot Core 缺陷确认与分诊 | 代部署、代运维、7×24 值守、驻场 |
| 官方文档指引 | 企业网络、数据库、Kubernetes、模型供应商故障排查 |
| 升级兼容性建议 | 插件、第三方适配器、私有协议客户端维护 |
| 公开版本信息与安全公告 | 定制开发、历史数据迁移 |
| 工单受理与分诊 | 恢复 SLA、固定修复期限、合规认证 |

定制需求不属于订阅范围，默认不承接。具有通用价值的需求可提交到公开 Roadmap。

## 首次响应

两档均承诺 **2 个工作日内首次人工响应**。首次响应是指人工确认问题范围、请求补充资料或给出初步分类，自动通知邮件不算。

<Warning>
首次响应不等于修复或恢复。修复进度取决于问题严重程度、可复现性，以及问题是否属于 LangBot Core。
</Warning>

- **受理时间**：中国大陆法定工作日 09:00–18:00（北京时间），调休工作日计入，法定节假日顺延。
- **计时方式**：受理时间内提交的，从提交时刻起算两个工作日；受理时间外提交的，从下一个工作日 09:00 起算。
- **示例**：周五 14:00 提交，最晚下周二 14:00 前响应；周五 20:00 提交，最晚下周三 09:00 前响应。

## 支持版本

- 服务面向 LangBot Core **当前稳定版本**。旧版本问题会先给出升级建议，确认缺陷时可能需要在当前稳定版本上复现。
- 不提供历史版本补丁、LTS 分支或客户私有补丁。
- 插件和第三方组件不属于 Core 维护范围。

## 咨询与额度

| | 企业支持计划 | 企业保障计划 |
| --- | --- | --- |
| 年度使用情况沟通（60 分钟） | 1 次 | 1 次 |
| 远程技术咨询（60 分钟，需预约） | — | 4 次 |

未使用的次数不结转到下一年。企业支持计划提供工单分诊、文档指引和缺陷确认，不包含对客户环境的持续远程排查。

## 实例登记（保障计划）

- 保障计划覆盖 **1 个登记的生产实例**。登记只用于界定支持范围，不限制 Apache 2.0 允许的部署数量，也不需要许可证或遥测。
- 登记内容：版本、部署概要、用途和联系人。更换生产实例时请通过工单更新登记。

## 安全信息

- 季度摘要基于公开的版本与安全信息。
- 严重安全问题通知基于维护团队确认的公告；我们不承诺判断您的环境是否受影响。
- 年度版本、依赖与安全状态说明（保障计划）基于登记版本和公开信息，不是安全审计、渗透测试或合规认证。

## 处理原则

- 一个工单对应一个问题，重复请求可能会被合并。
- 进入优先修复队列不代表有固定的修复时间；Roadmap 优先评审不代表承诺开发或排期。
- 支持统一通过工单进行，不提供群聊一对一支持。

## 服务期限

服务语言、联系人、起止日期和适用的服务说明版本以合同为准。到期后不再受理新请求，已受理的工单按合同完成分诊或交接。订阅到期不影响您继续使用开源 LangBot。
