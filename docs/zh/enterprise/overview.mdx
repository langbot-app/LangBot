LangBot 企业支持订阅（LangBot Enterprise Support）面向需要**官方支持关系**和**正式采购凭证**的企业。您的订阅也将直接资助 LangBot 的持续开发。

<Info>
LangBot 仍按 Apache License 2.0 免费提供。企业支持订阅**不是商业使用许可**，不解锁任何功能，也不限制未订阅企业继续使用开源版本。
</Info>
