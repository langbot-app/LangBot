## 开通流程

1. **联系我们**：扫描下方二维码添加我们的企业微信，说明企业名称、意向档位和使用情况。
2. **确认报价**：确认支持范围、税费和发票事项，签订年度服务合同。
3. **付款登记**：按合同付款，登记联系人、Space 账号和服务期限。
4. **开始使用**：收到订阅证书和服务说明后，即可[提交支持工单](/zh/enterprise/submit-ticket)。

![扫码添加 LangBot 企业微信](/images/enterprise/wecom-contact.png)

使用微信或企业微信扫一扫；手机上可长按保存二维码后识别。

<Note>
首次联系只需提供企业名称、意向档位和使用概况。开票资料在签约前再提供，请勿通过公开工单或 GitHub 发送银行和税务信息。
</Note>

## 合同与发票

| 项目 | 说明 |
| --- | --- |
| 签约主体 | LangBot 项目运营主体，具体信息见报价与合同 |
| 合同标的 | LangBot 开源软件年度维护、版本信息与技术支持服务 |
| 计费方式 | 按签约企业收取年费，不按人数计费 |
| 发票内容 | 由财务根据可开票范围确认，如软件服务费、信息技术服务费或技术支持服务费 |

订阅费用不作为捐赠，也不作为软件商业使用授权费开具。

## 交付材料

- 服务订单与合同，注明服务期限和指定联系人
- 年度企业支持订阅证书（证明支持服务关系，不构成额外软件授权）
- 服务范围与响应说明（注明版本）、Space 工单入口和账号登记
- 保障计划：生产实例登记和技术咨询额度
- 服务期间的季度维护摘要、工单与咨询记录；保障计划另附年度版本、依赖与安全状态说明

官网企业支持者名单的展示需要单独授权，也可以选择匿名。服务说明后续的更新不会自动改变已签合同的权益。

## 续费

续费需要另行确认，不会自动扣款。开始、结束、取消和退款安排以合同为准。

订阅不包含 LangBot Cloud 的算力、模型额度或托管服务。订阅到期后，您仍可按 Apache 2.0 继续使用 LangBot。
