## 使用一行命令安装（lbctl）部署

```bash
lbctl upgrade --yes
```

这会备份数据、升级到最新稳定版并重新启动；升级失败时会自动恢复（原生部署）或保留备份供恢复（Docker 部署）。已是最新版本时只会提示，不会做任何改动。

- 先看升级计划：`lbctl upgrade --dry-run`
- 升级到指定版本：`lbctl upgrade --version v4.11.8 --yes`
- 升级 lbctl 本身：`lbctl update`，或重新执行一次一行命令安装脚本

详见[使用 lbctl 管理 LangBot](/zh/deploy/lbctl#升级-langbot)。

## 使用包管理器（uvx）部署

请在之前使用包管理器部署的目录下重新执行：

```bash
uvx langbot@latest
```

这将重新下载并启动最新版本的 LangBot。

## 使用 Docker（或基于 Docker 的一键部署）

<Tip>
用 `docker compose` 部署的实例可以[接入 lbctl](/zh/deploy/lbctl#已有的-docker-compose-部署接入-lbctl)，之后同样只需 `lbctl upgrade --yes`，并且升级前会自动备份数据。下面是不使用 lbctl 时的手动方式。
</Tip>

请在之前 Clone 的 LangBot 目录下执行：

```bash
git pull
```

并在 `docker/` 目录下执行：

```bash
docker compose up --force-recreate --pull always -d
```

此命令将拉取最新的 LangBot 镜像并重建容器。

<Info>
4.3.0 版本更改了 `docker/docker-compose.yaml` 文件的内容和位置，若您由之前版本更新而来，请[根据文档重新部署](/zh/deploy/langbot/docker)。
</Info>

## 手动部署

从 [Releases](https://github.com/langbot-app/LangBot/releases) 页面下载最新发行版的 Assets 下的 `langbot-<version>-all.zip`，解压到原来部署到目录重启即可。
