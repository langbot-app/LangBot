## 安装主程序

1. 前往[Release](https://github.com/langbot-app/LangBot/releases)页面下载最新版本的压缩包（推荐）`langbot-xxx-all.zip`（请勿下载 Source Code，因为其中不包含 WebUI）。解压，在解压目录打开命令行（终端）

![下载Release](/images/zh/deploy/langbot/manual/dl_release.png)

2. 安装依赖

我们使用 [uv](https://docs.astral.sh/uv/) 管理依赖。

```bash
pip install uv
uv sync
```

默认安装不包含可选的向量数据库支持。如需使用以下后端，在 `uv sync` 时加上对应的 extra（可组合）：

| 后端 | extra |
| --- | --- |
| SeekDB 向量数据库 / 内置嵌入模型 | `seekdb` |
| Milvus | `milvus` |
| Valkey Search（不支持 Windows） | `valkey` |

```bash
uv sync --extra seekdb
```

SeekDB 嵌入式模式的平台支持取决于 `pylibseekdb` wheel；Apple Silicon 当前要求 macOS 15 或更高版本。其他功能仍可使用默认的 `uv sync` 安装。

### 可选的语音转码支持（SILK / 微信原生语音）

如果需要在微信等平台发送原生语音条（SILK 编码）或进行高级音频格式转码，需要系统安装 `ffmpeg` 并安装 `audio` 扩展依赖：

- **系统依赖**：`ffmpeg`（macOS 可用 `brew install ffmpeg`，Ubuntu/Debian 可用 `sudo apt-get install -y ffmpeg`，Windows 可用 `winget install Gyan.FFmpeg`）
- **Python 扩展**：
  ```bash
  uv sync --extra audio
  # 或同时启用 seekdb 与 audio
  uv sync --extra seekdb --extra audio
  ```

若未安装转码依赖，系统在需要转码为微信原生语音条时会自动进行**优雅降级**，将语音以音频文件的形式发送，确保用户仍能正常点击播放。

或者使用清华源

```bash
pip install uv -i https://pypi.tuna.tsinghua.edu.cn/simple
uv sync
```

3. 运行一次主程序，生成配置文件

```bash
uv run main.py
```
