本文把你的 n8n 应用接到KOOK机器人上。LangBot 接收KOOK消息，交给流水线处理后把答案发回去，你不需要写任何平台对接代码。

n8n 负责执行工作流，LangBot 负责聊天平台接入、会话和消息投递，并在每条消息到来时通过 Webhook 调用你的工作流。

## 准备工作

- 一个运行中的 LangBot：[LangBot Cloud](https://space.langbot.app/cloud)（无需服务器），或用 Docker、`uvx langbot` [自行部署](/zh/deploy/langbot/docker)。
- LangBot 能通过网络访问到的 n8n 账号或实例。
- 在 KOOK 开发者中心创建的机器人及其 **Bot Token**。

## 网络要求

KOOK 适配器只需要 Bot Token，由 LangBot 主动连接 KOOK。

## 1. 准备 n8n

1. 工作流以 **Webhook** 或 **On chat message** 触发器开始；需要流式回复时把 **Response Mode** 设为 **Streaming**。
2. 用 **AI Agent** 节点（流式）或 **Respond to Webhook** 节点返回结果，响应字段名要与 LangBot 中的输出键名一致。
3. 点击 **Active** 启用工作流，复制生产环境的 Webhook 地址。

## 2. 创建流水线

在 LangBot WebUI 打开 **流水线**，新建流水线（或编辑默认流水线），按下表配置 **AI** 能力。如果列表里没有对应运行器，请先在 **插件** 或 [LangBot Space 插件市场](https://space.langbot.app/market) 安装官方运行器插件。

| 配置项 | 填写 |
| --- | --- |
| 运行器 | **n8n**（官方 n8n 工作流运行器插件） |
| Webhook URL | 工作流的生产环境 Webhook 地址 |
| 认证方式 | 无、Basic Auth、JWT 或 Header，与触发节点设置一致 |

## 3. 创建KOOK机器人

1. 新建机器人，选择 **KOOK** 适配器并填写 Bot Token。
2. 为机器人配置权限并邀请进你的服务器。

## 4. 绑定并测试

打开机器人，选择刚才创建的流水线，保存并确认机器人已启用。

在机器人可读的频道中发送满足触发规则的消息。

## 常见问题排查

- 回复为空：**Respond to Webhook** 中的字段名必须与 LangBot 配置的输出键名一致。
- 测试地址只在 n8n 编辑器监听时可用，请使用已激活工作流的生产地址。
- 频道中没有回复：检查机器人的频道权限以及流水线的群聊触发规则。
- 在 WebUI 的 **监控** 页面可以看到每条消息、每次流水线运行和错误详情。

## 常见问题

### 接入KOOK需要有公网 IP 的服务器吗？

不需要。KOOK 适配器只需要 Bot Token，由 LangBot 主动连接 KOOK。

### KOOK机器人支持流式回复吗？

请查看[平台功能对照表](/zh/insight/platform-features)了解该平台支持的能力；AI 后端生成完成后会一次性发送回复。

### 同一套 n8n 配置能同时用在其他平台吗？

可以。一条流水线可以绑定多个机器人，同一套配置能同时在多个平台上回复。
