本文把 Ollama 模型接到企业微信应用机器人上。LangBot 接收企业微信应用消息，交给流水线处理后把答案发回去，你不需要写任何平台对接代码。

用 Ollama 在本地运行开源模型，通过 LangBot 内置 Agent 提供服务，对话数据不出你的机器。

## 准备工作

- 一个运行中的 LangBot：[LangBot Cloud](https://space.langbot.app/cloud)（无需服务器），或用 Docker、`uvx langbot` [自行部署](/zh/deploy/langbot/docker)。
- 可以从 LangBot 调用的 Ollama 账号或服务。
- 企业微信自建应用：**企业 ID**、应用 **Secret**、**通讯录同步 Secret**，以及回调用的 **Token** 和 **EncodingAESKey**。

## 网络要求

企业微信通过回调地址推送消息，因此 LangBot 需要可公网访问的域名和 HTTPS（参考[反向代理与 SSL](/zh/workshop/production/proxy-and-ssl)）。LangBot Cloud 自带可直接使用的公网地址。

## 1. 添加 Ollama 模型

1. 安装 Ollama 并拉取模型（`ollama pull` 加模型名）。
2. 在 LangBot 的 **模型** 页面新增 LLM 模型，供应商选 Ollama，请求地址指向你的 Ollama 服务（默认端口 `11434`）。
3. 如果 LangBot 运行在 Docker 中，`localhost` 指的是容器本身，请改用宿主机地址（例如 `host.docker.internal`）。

## 2. 创建流水线

在 LangBot WebUI 打开 **流水线**，新建流水线（或编辑默认流水线），按下表配置 **AI** 能力。

| 配置项 | 填写 |
| --- | --- |
| 运行器 | **内置 Agent** |
| 模型 | 刚添加的模型，可以再加备用模型。 |
| 提示词 | 机器人的身份、语气以及不能做的事。 |
| 知识库 | 可选。绑定知识库后按你的资料回答。 |

## 3. 创建企业微信应用机器人

1. 新建机器人，选择 **企业微信** 适配器，填写企业 ID、应用 Secret 和通讯录同步 Secret，启用后复制 Webhook 回调地址。
2. 在企业微信管理后台打开 **接收消息 → 设置 API 接收**，填入回调地址，随机生成 Token 和 EncodingAESKey，先在 LangBot 保存，再回到企业微信保存。最后在 **企业可信 IP** 中加入 LangBot 的出口 IP。

## 4. 绑定并测试

打开机器人，选择刚才创建的流水线，保存并确认机器人已启用。

在企业微信客户端打开该应用并发送消息。

## 常见问题排查

- 小型本地模型的工具调用能力可能较弱；不支持函数调用的模型请不要勾选 **工具调用**。
- 保存回调时提示 **请求 URL 失败**：回调地址无法通过公网 HTTPS 访问，或 LangBot 中的 Token/EncodingAESKey 不一致。
- 无法发出回复：把 LangBot 的出口 IP 加入企业可信 IP。
- 在 WebUI 的 **监控** 页面可以看到每条消息、每次流水线运行和错误详情。

## 常见问题

### 接入企业微信应用需要有公网 IP 的服务器吗？

需要，或者直接使用 LangBot Cloud。企业微信通过回调地址推送消息，因此 LangBot 需要可公网访问的域名和 HTTPS（参考[反向代理与 SSL](/zh/workshop/production/proxy-and-ssl)）。LangBot Cloud 自带可直接使用的公网地址。

### 企业微信应用机器人支持流式回复吗？

请查看[平台功能对照表](/zh/insight/platform-features)了解该平台支持的能力；AI 后端生成完成后会一次性发送回复。

### 同一套 Ollama 配置能同时用在其他平台吗？

可以。一条流水线可以绑定多个机器人，同一套配置能同时在多个平台上回复。
