本文把你的 Coze 应用接到Telegram机器人上。LangBot 接收Telegram消息，交给流水线处理后把答案发回去，你不需要写任何平台对接代码。

扣子（Coze）可以可视化搭建智能体。LangBot 通过 Coze API 调用你的智能体，让它出现在扣子本身不支持发布的平台上，并在多个渠道共用同一个智能体。

## 准备工作

- 一个运行中的 LangBot：[LangBot Cloud](https://space.langbot.app/cloud)（无需服务器），或用 Docker、`uvx langbot` [自行部署](/zh/deploy/langbot/docker)。
- LangBot 能通过网络访问到的 Coze 账号或实例。
- 通过 [@BotFather](https://t.me/BotFather) 获取的机器人 Token（发送 `/newbot`，用户名需以 `bot` 结尾）。

## 网络要求

Telegram 使用长轮询：LangBot 只需要能访问 `api.telegram.org`，不需要公网 Webhook 地址，本地电脑或家用服务器也能运行。

## 1. 准备 Coze

1. 在扣子开发者控制台的 **API 管理** 中创建令牌（coze.cn 支持服务身份长期凭据，coze.com 只提供个人访问令牌）。
2. 发布智能体时勾选 **API** 渠道，并记录 `bot_id`。

## 2. 创建流水线

在 LangBot WebUI 打开 **流水线**，新建流水线（或编辑默认流水线），按下表配置 **AI** 能力。如果列表里没有对应运行器，请先在 **插件** 或 [LangBot Space 插件市场](https://space.langbot.app/market) 安装官方运行器插件。

| 配置项 | 填写 |
| --- | --- |
| 运行器 | **扣子**（官方扣子 Agent 运行器插件） |
| API Key | 扣子令牌 |
| Bot ID | 智能体的 `bot_id` |
| API Base URL | coze.cn 填 `https://api.coze.cn`，coze.com 填 `https://api.coze.com` |

## 3. 创建Telegram机器人

1. 在 **机器人** 页面新建机器人，选择 **Telegram** 适配器（LangBot 4.11 的新适配器，不要选已弃用的旧版）。
2. 填入 Token，按需开启 Markdown 和流式输出，启用并保存。

## 4. 绑定并测试

打开机器人，选择刚才创建的流水线，保存并确认机器人已启用。

在与机器人的私聊中点击 **Start** 后发送消息。群聊中消息需要满足流水线的触发规则（例如 @ 机器人或回复它的消息）。

## 常见问题排查

- 调用失败：检查令牌和 `bot_id` 是否带了多余空格、智能体发布时是否勾选了 API 渠道、Base URL 是否与所用站点一致。
- 同一个 Token 只能被一个实例轮询。如果收不到回复，请确认没有在其他 LangBot 实例或脚本中启用同一个机器人。
- 在 WebUI 的 **监控** 页面可以看到每条消息、每次流水线运行和错误详情。

## 常见问题

### 接入Telegram需要有公网 IP 的服务器吗？

不需要。Telegram 使用长轮询：LangBot 只需要能访问 `api.telegram.org`，不需要公网 Webhook 地址，本地电脑或家用服务器也能运行。

### Telegram机器人支持流式回复吗？

支持。在机器人上开启流式输出，同时 AI 后端也要支持流式。详见[平台功能对照表](/zh/insight/platform-features)。

### 同一套 Coze 配置能同时用在其他平台吗？

可以。一条流水线可以绑定多个机器人，同一套配置能同时在多个平台上回复。
