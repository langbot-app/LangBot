本文把 Qwen 模型接到飞书机器人上。LangBot 接收飞书消息，交给流水线处理后把答案发回去，你不需要写任何平台对接代码。

通过阿里云百炼（DashScope）用 LangBot 内置 Agent 调用通义千问模型。

## 准备工作

- 一个运行中的 LangBot：[LangBot Cloud](https://space.langbot.app/cloud)（无需服务器），或用 Docker、`uvx langbot` [自行部署](/zh/deploy/langbot/docker)。
- 可以从 LangBot 调用的 Qwen 账号或服务。
- 飞书或 Lark 自建应用（`app_id` 与 `app_secret`）。可以直接用 LangBot 的一键创建完成创建与授权。

## 网络要求

默认的 WebSocket 长连接模式不需要公网 IP。长连接不可用时（例如部分国际版 Lark），需要改用 Webhook 模式，此时需要公网 HTTPS 地址；LangBot Cloud 自带该地址。

## 1. 添加 Qwen 模型

1. 在 Aliyun Bailian (DashScope) 控制台创建 API Key。
2. 在 LangBot 的 **模型** 页面新增 LLM 模型，供应商选择 Aliyun Bailian (DashScope)，请求地址填写 `https://dashscope.aliyuncs.com/compatible-mode/v1`，再填入 API Key 和模型名称。
3. 如果模型支持函数调用，请勾选 **工具调用**；MCP 工具、Skills 和沙箱都依赖它。
4. 模型名使用百炼控制台中列出的通义千问模型 ID。

## 2. 创建流水线

在 LangBot WebUI 打开 **流水线**，新建流水线（或编辑默认流水线），按下表配置 **AI** 能力。

| 配置项 | 填写 |
| --- | --- |
| 运行器 | **内置 Agent** |
| 模型 | 刚添加的模型，可以再加备用模型。 |
| 提示词 | 机器人的身份、语气以及不能做的事。 |
| 知识库 | 可选。绑定知识库后按你的资料回答。 |

## 3. 创建飞书机器人

1. 新建机器人，选择 **飞书** 适配器，选择平台域名（飞书或 Lark）后使用 **一键创建**，或手动填写 `app_id` 与 `app_secret`。
2. 按文档补充消息权限和事件订阅（需要流式卡片时再加卡片权限），然后发布应用版本。

## 4. 绑定并测试

打开机器人，选择刚才创建的流水线，保存并确认机器人已启用。

在飞书中搜索机器人并私聊，再把它拉进群里 @ 它测试。

## 常见问题排查

- 国际站账号的 DashScope 地址不同，请以控制台显示的 OpenAI 兼容地址为准。
- 收不到消息：确认应用版本已发布，且事件订阅方式（长连接或 Webhook）与 LangBot 配置一致。
- 在 WebUI 的 **监控** 页面可以看到每条消息、每次流水线运行和错误详情。

## 常见问题

### 接入飞书需要有公网 IP 的服务器吗？

不一定。默认的 WebSocket 长连接模式不需要公网 IP。长连接不可用时（例如部分国际版 Lark），需要改用 Webhook 模式，此时需要公网 HTTPS 地址；LangBot Cloud 自带该地址。

### 飞书机器人支持流式回复吗？

支持。在机器人上开启流式输出，同时 AI 后端也要支持流式。详见[平台功能对照表](/zh/insight/platform-features)。

### 同一套 Qwen 配置能同时用在其他平台吗？

可以。一条流水线可以绑定多个机器人，同一套配置能同时在多个平台上回复。
