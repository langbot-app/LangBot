本文把你的 Dify 应用接到LINE机器人上。LangBot 接收LINE消息，交给流水线处理后把答案发回去，你不需要写任何平台对接代码。

Dify 可以搭建聊天助手、Chatflow、Agent 和工作流。LangBot 通过 Service API 调用你发布的应用，提示词、工具和知识库都留在 Dify 里维护。

## 准备工作

- 一个运行中的 LangBot：[LangBot Cloud](https://space.langbot.app/cloud)（无需服务器），或用 Docker、`uvx langbot` [自行部署](/zh/deploy/langbot/docker)。
- LangBot 能通过网络访问到的 Dify 账号或实例。
- 在 [LINE Developers Console](https://developers.line.biz/) 创建的 Messaging API Channel：**Channel Secret** 和 **Channel Access Token**（点击 **Issue** 生成）。

## 网络要求

LINE 通过 Webhook 推送消息，LangBot 需要公网 HTTPS 地址；LangBot Cloud 自带域名和 HTTPS。

## 1. 准备 Dify

1. 在 Dify 中搭建并 **发布** 聊天助手（含 Chatflow）、Agent 或工作流应用。
2. 进入应用的 **访问 API** 页面生成 API Key。
3. 如果是工作流应用，请用 `summary` 作为输出变量名。

## 2. 创建流水线

在 LangBot WebUI 打开 **流水线**，新建流水线（或编辑默认流水线），按下表配置 **AI** 能力。如果列表里没有对应运行器，请先在 **插件** 或 [LangBot Space 插件市场](https://space.langbot.app/market) 安装官方运行器插件。

| 配置项 | 填写 |
| --- | --- |
| 运行器 | **Dify**（官方 Dify Agent 运行器插件） |
| Base URL | Dify 云服务填 `https://api.dify.ai/v1`；自部署填你的 Dify 地址并加上 `/v1` |
| API Key | 应用访问 API 页面生成的密钥 |

## 3. 创建LINE机器人

1. 新建机器人，选择 **LINE** 适配器，填写 Channel Secret 和 Channel Access Token。
2. 把 LangBot 中的 Webhook 回调地址填入 Channel 的 **Webhook URL**，验证后开启 **Use webhook**。

## 4. 绑定并测试

打开机器人，选择刚才创建的流水线，保存并确认机器人已启用。

扫描二维码添加官方账号为好友并发送消息。

## 常见问题排查

- 自部署的 Dify 与 LangBot 在同一台机器的 Docker 中：让两边加入同一个 Docker 网络，用容器地址（例如 `http://dify-nginx/v1`），不要用 `localhost`。
- Chatflow 应用只会返回 “直接回复” 节点输出的内容。
- Webhook 验证失败：检查地址是否正确、HTTPS 能否从公网访问。
- 没有回复：在 Official Account Manager 中关闭 LINE 自带的自动回复，避免它代替机器人回复。
- 在 WebUI 的 **监控** 页面可以看到每条消息、每次流水线运行和错误详情。

## 常见问题

### 接入LINE需要有公网 IP 的服务器吗？

需要，或者直接使用 LangBot Cloud。LINE 通过 Webhook 推送消息，LangBot 需要公网 HTTPS 地址；LangBot Cloud 自带域名和 HTTPS。

### LINE机器人支持流式回复吗？

请查看[平台功能对照表](/zh/insight/platform-features)了解该平台支持的能力；AI 后端生成完成后会一次性发送回复。

### 同一套 Dify 配置能同时用在其他平台吗？

可以。一条流水线可以绑定多个机器人，同一套配置能同时在多个平台上回复。
