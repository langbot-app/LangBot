# 仅插件消息处理

在部署的数据配置 `data/config.yaml` 中设置以下内容，然后重启 LangBot：

```yaml
system:
  plugin_only: true
```

LangBot 仍按 Pipeline 的插件绑定调用消息和命令监听器。插件通过 `prevent_default()` 接管消息后的回复和后台任务保持正常；未被插件接管的普通消息、命令静默结束，不进入 AI Runner，也不执行内置命令或发送运行器缺失提示。

此开关对实例内的全部 Pipeline 生效，默认值为 `false`。机器人的平台订阅、插件启用状态和各 Pipeline 的插件白名单仍独立控制。插件自己的主动消息、定时任务和错误回复由各插件配置决定。

平台事件路由到 AI Agent 时也会静默跳过；路由到 Pipeline 和显式订阅的插件事件处理器仍会执行。

在此模式下执行流水线迁移，会把旧 AI 运行方式归档到工作区所属的迁移快照中，并将当前流程保存为未选择 AI Runner 的新版格式。插件白名单、消息规则和其余设置保留；原本未配置模型的流程也可以迁移，无需安装 LocalAgent。关闭此模式后，如需 AI 回复，应在流程中明确选择运行器并重新配置模型，或依据迁移快照恢复旧设置。

升级后应先核对插件全部处于 `initialized`，再验证普通群消息没有回复、插件匹配消息维持处理。只检查网页 HTTP 状态不足以验证此部署模式。
