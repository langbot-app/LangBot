title: "ボット（Bots）"

ボットは、メッセージングプラットフォームからメッセージイベントを受信し、パイプラインを呼び出してメッセージを処理するために使用されます。

<Tip>
**パブリック IP やドメインの設定が面倒ですか？** Slack、LINE、WeCom、Lark などのプラットフォームでは Webhook コールバック URL が必要で、パブリックサーバー、ドメイン、HTTPS 証明書が必要です。[LangBot Cloud](https://space.langbot.app/cloud) にはドメイン解決と HTTPS が組み込まれており、登録するだけですぐに使用できます。
</Tip>
