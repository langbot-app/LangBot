**企業微信カスタマーサービスアカウントのデプロイには企業資格が必要です**。[企業微信カスタマーサービス統合ガイド](https://developer.work.weixin.qq.com/document/path/94638)を確認し、このドキュメントに従って対応する企業資格証明書を提供してください。

</Info>

## 企業微信カスタマーサービスをデプロイする

#### 企業微信カスタマーサービスページの構成

[企業微信カスタマーサービス管理画面](https://kf.weixin.qq.com/kf)を開き、ログイン後、「企業情報」をクリックし、「企業ID」を取得します。

![ホーム画面](/images/zh/deploy/bots/wecom/wecomcs/wecomcs_03.png)

企業IDを保存したら、「開発構成」をクリックし、「開始使用」をクリックして、Token と EncodingAESKey をランダムに生成します。この3つの項目を LangBot 設定ページに入力します。Secret は適当に填写如下图所示：

![connect](/images/zh/deploy/bots/wecom/wecomcs/connect_to_langbot.png)

LangBot 設定ページの提交をクリックして 로봇を有効化し、Webhook コールバックアドレスをコピーし、企業微信カスタマーサービス管理画面の URL に入力します（自分の IP またはドメインに変更することを忘れないでください）。保存をクリックし、成功すれば正常に接続できることを意味します。

<Tip>
**ドメイン設定が面倒ですか？** [LangBot Cloud](https://space.langbot.app/cloud) にはドメインと HTTPS が含まれており、設定不要ですぐに使用できます。
</Tip>

ページの Secret をコピーし、新しく作成した LangBot 企業微信カスタマーサービス 로봇を開き、新しい Secret を入力して再起動します。

## 問い合わせリンクと QR コードを取得する

コールバックの設定後、WeChat ユーザーが問い合わせを開始するためのリンクまたは QR コードを取得します。

1. [WeChat カスタマーサービス管理画面](https://kf.weixin.qq.com/kf)に戻り、`客服帐号`（カスタマーサービスアカウント）から、LangBot に接続するアカウントを作成または選択します。
2. アカウントの接続ページを開き、`在微信外App/网页中接入`（WeChat 外のアプリ・Web ページに接続）までスクロールして、`去接入` をクリックします。

![WeChat 外のアプリ・Web ページへの接続入口](/images/zh/deploy/bots/wecom/wecomcs/customer-service-entry.png)

3. 接続ページ上部の対象アカウントで、`复制链接` をクリックすると問い合わせリンクをコピーでき、`生成二维码` をクリックすると QR コードを表示できます。

![問い合わせリンクのコピーと QR コードの生成](/images/zh/deploy/bots/wecom/wecomcs/customer-service-link.png)

<Note>
スクリーンショットのリンクは例です。自分のアカウントで生成したリンクまたは QR コードを使用してください。Webhook コールバック URL は LangBot へのイベント通知用で、問い合わせリンクと QR コードはユーザーが会話を開始するためのものです。
</Note>

## QR コードで動作を確認する

1. LangBot のボットを有効にし、イベントルーティングで「メッセージ受信」イベントを使用するプロセッサーに割り当てます。
2. 通常の WeChat で生成した QR コードを読み取り、カスタマーサービスの会話を開いてメッセージを送信します。
3. LangBot のボットログ、セッション監視、対象プロセッサーの実行ログで受信と処理を確認し、WeChat に返信が届くことを確認します。

QR コードで動作を確認するだけなら、接続ページ下部のアプリ連携を設定する必要はありません。

## ルーティングできるイベント

ボットのイベントルーティングで、イベントごとにプロセッサーを選択できます。通常のメッセージにはパイプラインまたは Agent、それ以外には対象イベントに対応した Agent またはプラグインプロセッサーを使用します。

| イベント | イベントタイプ |
| --- | --- |
| メッセージ受信 | `message.received` |
| 顧客または担当者によるメッセージ撤回 | `message.deleted` |
| 顧客がリンクから会話に参加 | `wecomcs.enter_session` |
| メッセージ送信失敗 | `wecomcs.msg_send_fail` |
| 担当者の受付状態変更 | `wecomcs.servicer_status_change` |
| 会話の受付、転送、終了、再開 | `wecomcs.session_status_change` |
| 顧客メッセージの受信拒否設定変更 | `wecomcs.reject_customer_msg_switch_change` |

撤回イベントには元のメッセージ ID、操作者、チャット ID が含まれます。カスタマーサービス固有のイベントにはアカウント、顧客、`welcome_code`、`fail_type`、`change_type` などの関連フィールドが含まれます。未知のイベントは `platform.specific` として元のデータを保持します。

会話への参加イベントはリンクから入った場合に発生し、既存のチャット一覧から開いても発生しません。歓迎メッセージを送るにはプロセッサーの処理を設定してください。イベントの受信だけでは送信されません。

### 返信期限と歓迎メッセージ

- 通常の返信には顧客からのメッセージが必要で、48 時間以内に送信する必要があります。会話への参加だけではこの条件を満たしません。エラー `95002` は送信期限の条件を満たしていないことを示します。
- 参加イベントでの Agent の `event_reply` は、専用のイベント応答 API と `welcome_code` を使います。このコードは歓迎メッセージの条件を満たす場合のみ提供され、送信できるのは 1 件、有効期限は 20 秒です。時間のかかるモデル生成より、すぐに送信できる固定文面を推奨します。
- 会話状態変更イベントの `event_reply` は `msg_code` を使用し、有効期限と現在の会話状態による制限を受けます。現在のイベント返信はテキストに対応しています。コードがない場合、期限切れの場合、使用済みの場合は再送できません。古いイベントを再実行しても有効期限は延長されません。

詳細は公式の[メッセージ送信](https://developer.work.weixin.qq.com/document/path/94677)と[イベント応答送信](https://developer.work.weixin.qq.com/document/path/95122)を参照してください。
