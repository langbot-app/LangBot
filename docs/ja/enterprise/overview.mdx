LangBot エンタープライズサポート（LangBot Enterprise Support）は、**公式のサポート関係**と**正式な調達書類**を必要とする企業向けのサービスです。購読料は LangBot の継続的な開発にも直接充てられます。

<Info>
LangBot は引き続き Apache License 2.0 で無料提供されます。本サービスは**商用利用ライセンスではありません**。機能の解除はなく、未契約企業の利用も制限しません。
</Info>

## プラン

| | 企業サポートプラン | 企業保障プラン |
| --- | --- | --- |
| 年額（米ドル） | US$2,900 | US$7,500 |
| 対象 | 正式なサポート関係を結び、プロジェクトを支援したい企業 | LangBot を本番環境で利用している企業 |
| 契約書・請求書・年次証明書 | ✓ | ✓ |
| 企業チケット、2 営業日以内の初回応答 | ✓ | ✓ |
| 重大なセキュリティ通知、四半期のリリース・セキュリティまとめ | ✓ | ✓ |
| 年次利用状況レビュー（60 分） | 1 回 | 1 回 |
| 公開ロードマップ提案の優先審査 | ✓ | ✓ |
| 支援企業一覧への掲載（同意制、匿名可） | ✓ | ✓ |
| 本番インスタンスの登録 | — | 1 件 |
| リモート技術相談（各 60 分） | — | 年 4 回 |
| 更新前の互換性相談、障害の優先切り分け | — | ✓ |
| 確認済み Core 不具合の優先修正キュー登録 | — | ✓ |
| 年次のバージョン・依存関係・セキュリティ状態の説明 | — | ✓ |

料金は契約企業単位の年額で、人数やデプロイ数による課金はありません。税金、請求書の種類、サービス期間は正式な見積・契約によります。
