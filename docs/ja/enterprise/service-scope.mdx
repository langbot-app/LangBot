title: "サービス範囲と応答"
description: "エンタープライズサポートの対象・対象外と、初回応答時間の計算方法。"
---

エンタープライズサポートの対象は **LangBot Core そのもの**です。統一チケット窓口での切り分けと案内を提供し、運用代行やカスタム開発は行いません。

## 対象と対象外

| 対象 | 対象外 |
| --- | --- |
| LangBot Core の不具合確認と切り分け | 導入代行、運用代行、24 時間対応、常駐 |
| 公式ドキュメントの案内 | 顧客のネットワーク、データベース、Kubernetes、モデル提供者の障害調査 |
| 更新時の互換性に関する助言 | プラグイン、第三者アダプター、非公開プロトコルクライアントの保守 |
| 公開リリース情報とセキュリティ告知 | カスタム開発、過去データの移行 |
| チケットの受付と切り分け | 復旧 SLA、修正期限の保証、適合性認証 |

カスタム開発は対象外で、原則としてお受けしていません。汎用的な要望は公開ロードマップに提案できます。

## 初回応答

両プランとも **2 営業日以内の初回有人応答**をお約束します。初回応答とは、担当者が範囲を確認する、追加情報を依頼する、または初期分類を行うことを指し、自動通知メールは含みません。

<Warning>
初回応答は修正や復旧の保証ではありません。修正は重大度、再現性、LangBot Core の問題かどうかによります。
</Warning>

- **受付時間**：中国本土の営業日 09:00–18:00（北京時間）。振替出勤日を含み、法定休日は除きます。
- **計算方法**：受付時間内の依頼は送信時刻から、時間外の依頼は翌営業日 09:00 から数えます。
- **例**：金曜 14:00 に送信 → 火曜 14:00 までに応答。金曜 20:00 に送信 → 水曜 09:00 までに応答。

## 対象バージョン

- 対象は LangBot Core の**最新安定版**です。旧バージョンではまず更新をご提案し、不具合の確認には最新安定版での再現をお願いする場合があります。
- 過去バージョンへのバックポート、LTS ブランチ、個別パッチは提供しません。
- プラグインや第三者コンポーネントは Core の保守対象外です。

## 相談と回数

| | 企業サポートプラン | 企業保障プラン |
| --- | --- | --- |
| 年次利用状況レビュー（60 分） | 1 回 | 1 回 |
| リモート技術相談（60 分、要予約） | — | 4 回 |

未使用分は翌年に繰り越せません。企業サポートプランはチケットの切り分け、ドキュメント案内、不具合確認を提供し、顧客環境の継続的なリモート調査は含みません。

## インスタンス登録（保障プラン）

- 保障プランは**登録済みの本番インスタンス 1 件**が対象です。登録はサポート範囲を定めるためのもので、Apache 2.0 で認められるデプロイ数を制限せず、ライセンスキーやテレメトリーも不要です。
- 登録内容はバージョン、デプロイ概要、用途、担当者です。インスタンスを入れ替える場合はチケットで登録を更新してください。

## セキュリティ情報

- 四半期まとめは公開されたリリース・セキュリティ情報に基づきます。
- 重大なセキュリティ通知はメンテナーが確認した告知に基づきます。お客様の環境が影響を受けるかどうかの判定は行いません。
- 年次の状態説明（保障プラン）は登録バージョンと公開情報に基づくもので、セキュリティ監査、ペネトレーションテスト、適合性認証ではありません。

## 対応の原則

- 1 チケットにつき 1 件の問題とし、重複は統合する場合があります。
- 優先修正キューへの登録は修正期限を保証せず、ロードマップの優先審査も開発やスケジュールを約束するものではありません。
- サポートはチケットで行い、グループチャットでの個別対応は行いません。

## サービス期間

言語、担当者、サービス期間、適用されるサービス説明の版は契約で定めます。期間終了後は新しい依頼を受け付けず、受付済みのチケットは契約に従って切り分けまたは引き継ぎを行います。終了後もオープンソース版 LangBot は引き続き利用できます。
