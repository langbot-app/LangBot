title: "チケットの送信"

---

<Tip>
[LangBot Space でチケットを送信 →](https://space.langbot.app/profile?tab=tickets&language=ja)
</Tip>

## 手順

1. 契約で登録した Space アカウントでログインします。
2. **プロフィール → チケット**でテンプレートを選びます。
   - **Enterprise Support: issue intake**：LangBot Core の不具合と思われる問題の報告
   - **Enterprise Support: upgrade and consultation**：更新時の互換性、技術相談の予約（保障プラン）、ドキュメント・調達資料
3. 契約番号と企業名を入力し、フォームに記入します。

権利を確認する前に、契約、登録アカウント、サービス期間を照合します。契約番号だけでは本人確認になりません。

## 用意する情報

**問題の報告**

- LangBot のバージョンとデプロイ方法
- 期待する動作と実際の動作
- 再現手順
- マスキング済みのログ（ない場合は理由）
- 業務への影響

**更新・相談**

- 登録インスタンスと現在のバージョン、目標バージョン（該当する場合）
- 相談の目的と背景
- 希望日時（打ち合わせが必要な場合）

<Warning>
アクセストークン、パスワード、チャット履歴全体、個人情報、設定ファイルそのものは送信しないでください。スクリーンショットはマスキングしてください。脆弱性の詳細を公開 GitHub issue に投稿しないでください。
</Warning>

## 送信後

契約を確認したうえで切り分けを行い、次のいずれかで対応します。

- ドキュメントの案内、または追加情報の依頼
- 技術相談の予約（保障プラン）
- LangBot Core の不具合として確認し、公開の保守プロセスへ
- 対象外であることのご説明

確認された一般的な不具合は、必要最小限のマスキング済み再現情報のみを公開保守に回します。契約、ログ、業務情報が公開 GitHub に同期されることはありません。追加情報は同じチケットに返信してください。
