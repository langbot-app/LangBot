このレシピではお使いの Coze アプリを WeCom（社内アプリ） のボットにつなぎます。LangBot が WeCom（社内アプリ） のメッセージを受け取り、パイプラインで処理して返信するので、プラットフォーム連携のコードは不要です。

Coze ではエージェントをビジュアルに作れます。LangBot は Coze API で Coze ボットを呼び出すため、Coze が直接公開できないプラットフォームにも同じボットを展開できます。

## 必要なもの

- 稼働中の LangBot：[LangBot Cloud](https://space.langbot.app/cloud)（サーバー不要）、または Docker や `uvx langbot` による[セルフホスト](/ja/deploy/langbot/docker)。
- LangBot からネットワーク経由で到達できる Coze のアカウントまたはインスタンス。
- WeCom の自社開発アプリ：**企業 ID**、アプリの **Secret**、**連絡先同期 Secret**、コールバック用の **Token** と **EncodingAESKey**。

## ネットワーク

WeCom はコールバック URL にメッセージを送るため、LangBot には公開ドメインと HTTPS が必要です（[リバースプロキシと SSL](/ja/workshop/production/proxy-and-ssl) を参照）。LangBot Cloud にはすぐ使える公開 URL があります。

## 1. Coze を準備する

1. Coze の開発者コンソールの **API 管理** でトークンを作成します（coze.com は個人アクセストークン、coze.cn はサービス資格情報にも対応）。
2. 公開時に **API** チャネルを選んでエージェントを公開し、`bot_id` を控えます。

## 2. パイプラインを作成する

LangBot WebUI の **パイプライン** でパイプラインを作成（または既定のものを編集）し、**AI** を次のように設定します。ランナーが一覧にない場合は、**プラグイン** または [LangBot Space マーケット](https://space.langbot.app/market) から公式ランナープラグインをインストールします。

| 項目 | 設定値 |
| --- | --- |
| ランナー | **Coze**（公式 Coze Agent ランナープラグイン） |
| API Key | Coze のトークン |
| Bot ID | エージェントの `bot_id` |
| API Base URL | coze.cn は `https://api.coze.cn`、coze.com は `https://api.coze.com` |

## 3. WeCom（社内アプリ） のボットを作成する

1. **WeCom** アダプターでボットを作成し、企業 ID、アプリ Secret、連絡先同期 Secret を入力して有効化し、Webhook コールバック URL をコピーします。
2. WeCom 管理画面の **メッセージ受信 → API 受信の設定** に URL を貼り、Token と EncodingAESKey を生成して、先に LangBot、次に WeCom で保存します。LangBot の送信元 IP を **企業の信頼 IP** に追加します。

## 4. 紐付けてテストする

ボットを開いて作成したパイプラインを選び、保存してボットが有効になっていることを確認します。

WeCom クライアントでアプリを開き、メッセージを送ります。

## トラブルシューティング

- 呼び出しに失敗する場合は、トークンと `bot_id` に余分な空白がないか、API チャネルで公開したか、Base URL が利用サイトと一致しているかを確認します。
- コールバック保存時に **request URL failed** となる場合は、URL が公開 HTTPS で到達できないか、LangBot の Token/EncodingAESKey が一致していません。
- 返信が送れない場合は、LangBot の送信元 IP を企業の信頼 IP に追加します。
- WebUI の **モニタリング** に、すべてのメッセージ、パイプラインの実行、エラーが記録されます。

## よくある質問

### WeCom（社内アプリ） には公開 IP のあるサーバーが必要ですか？

必要です。または LangBot Cloud を使えます。WeCom はコールバック URL にメッセージを送るため、LangBot には公開ドメインと HTTPS が必要です（[リバースプロキシと SSL](/ja/workshop/production/proxy-and-ssl) を参照）。LangBot Cloud にはすぐ使える公開 URL があります。

### WeCom（社内アプリ） のボットはストリーミング返信に対応していますか？

対応状況は[プラットフォーム機能一覧](/ja/insight/platform-features)で確認してください。AI 側の生成が終わってから返信が送られます。

### 同じ Coze の設定を他のプラットフォームでも使えますか？

はい。1 つのパイプラインを複数のボットに紐付けられるので、同じ設定で複数のプラットフォームに同時に応答できます。
