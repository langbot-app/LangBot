このレシピでは Ollama のモデルを WeCom カスタマーサービス のボットにつなぎます。LangBot が WeCom カスタマーサービス のメッセージを受け取り、パイプラインで処理して返信するので、プラットフォーム連携のコードは不要です。

Ollama でオープンモデルをローカル実行し、LangBot の内蔵エージェントから提供します。会話データは手元のマシンから出ません。

## 必要なもの

- 稼働中の LangBot：[LangBot Cloud](https://space.langbot.app/cloud)（サーバー不要）、または Docker や `uvx langbot` による[セルフホスト](/ja/deploy/langbot/docker)。
- LangBot から呼び出せる Ollama のアカウントまたはサーバー。
- API を有効にした WeCom カスタマーサービス（WeChat Kefu）：**企業 ID**、**Secret**、コールバック用 **Token** と **EncodingAESKey**。

## ネットワーク

カスタマーサービスはコールバック URL にイベントを送るため、LangBot には公開 HTTPS アドレスが必要です。LangBot Cloud には用意されています。

## 1. Ollama のモデルを追加する

1. Ollama をインストールしてモデルを取得します（`ollama pull` にモデル名）。
2. LangBot の **モデル** で LLM モデルを追加し、プロバイダーに Ollama、リクエスト URL に Ollama サーバー（既定ポート `11434`）を指定します。
3. LangBot が Docker で動いている場合、`localhost` はコンテナ自身を指すため、ホストのアドレス（例：`host.docker.internal`）を使います。

## 2. パイプラインを作成する

LangBot WebUI の **パイプライン** でパイプラインを作成（または既定のものを編集）し、**AI** を次のように設定します。

| 項目 | 設定値 |
| --- | --- |
| ランナー | **Local Agent**（内蔵エージェント） |
| モデル | 追加したモデル。予備モデルも指定できます。 |
| プロンプト | ボットの役割、口調、してはいけないこと。 |
| ナレッジベース | 任意。ナレッジベースを付けると資料に基づいて回答します。 |

## 3. WeCom カスタマーサービス のボットを作成する

1. WeCom カスタマーサービスの **開発者設定** で Token と EncodingAESKey を生成し、企業 ID とともに **WeCom カスタマーサービス** アダプターのボットに入力します。
2. ボットを有効化して Webhook コールバック URL を管理画面に貼り、Secret を入力してボットを再起動します。ユーザーが会話を始めるためのリンクや QR コードを発行します。

## 4. 紐付けてテストする

ボットを開いて作成したパイプラインを選び、保存してボットが有効になっていることを確認します。

WeChat でカスタマーサービスのリンクを開くか QR コードを読み取り、メッセージを送ります。

## トラブルシューティング

- 小さなローカルモデルはツール呼び出しが苦手な場合があります。関数呼び出しに対応しないモデルでは **ツール使用** をオフにします。
- ウェルカムメッセージは WeChat が `welcome_code` を渡したときだけ、期限内に 1 回だけ送れます。
- WebUI の **モニタリング** に、すべてのメッセージ、パイプラインの実行、エラーが記録されます。

## よくある質問

### WeCom カスタマーサービス には公開 IP のあるサーバーが必要ですか？

必要です。または LangBot Cloud を使えます。カスタマーサービスはコールバック URL にイベントを送るため、LangBot には公開 HTTPS アドレスが必要です。LangBot Cloud には用意されています。

### WeCom カスタマーサービス のボットはストリーミング返信に対応していますか？

対応状況は[プラットフォーム機能一覧](/ja/insight/platform-features)で確認してください。AI 側の生成が終わってから返信が送られます。

### 同じ Ollama の設定を他のプラットフォームでも使えますか？

はい。1 つのパイプラインを複数のボットに紐付けられるので、同じ設定で複数のプラットフォームに同時に応答できます。
