このレシピではお使いの Dify アプリを LINE のボットにつなぎます。LangBot が LINE のメッセージを受け取り、パイプラインで処理して返信するので、プラットフォーム連携のコードは不要です。

Dify ではチャットアシスタント、Chatflow、エージェント、ワークフローを作れます。LangBot は公開したアプリを Service API 経由で呼び出すため、プロンプト、ツール、ナレッジは Dify 側で管理できます。

## 必要なもの

- 稼働中の LangBot：[LangBot Cloud](https://space.langbot.app/cloud)（サーバー不要）、または Docker や `uvx langbot` による[セルフホスト](/ja/deploy/langbot/docker)。
- LangBot からネットワーク経由で到達できる Dify のアカウントまたはインスタンス。
- [LINE Developers コンソール](https://developers.line.biz/) の Messaging API チャネル：**チャネルシークレット** と **チャネルアクセストークン**（**発行** をクリック）。

## ネットワーク

LINE は Webhook を呼び出すため、LangBot には公開 HTTPS URL が必要です。LangBot Cloud にはドメインと HTTPS があります。

## 1. Dify を準備する

1. Dify でチャットアシスタント（Chatflow を含む）、エージェント、ワークフローのいずれかを作成して **公開** します。
2. アプリの **API アクセス** ページで API キーを作成します。
3. ワークフローアプリの場合は、回答を `summary` というキーで出力します。

## 2. パイプラインを作成する

LangBot WebUI の **パイプライン** でパイプラインを作成（または既定のものを編集）し、**AI** を次のように設定します。ランナーが一覧にない場合は、**プラグイン** または [LangBot Space マーケット](https://space.langbot.app/market) から公式ランナープラグインをインストールします。

| 項目 | 設定値 |
| --- | --- |
| ランナー | **Dify**（公式 Dify Agent ランナープラグイン） |
| Base URL | Dify Cloud は `https://api.dify.ai/v1`、セルフホストは自分の Dify アドレスの末尾に `/v1` |
| API Key | アプリの API アクセスページで作成したキー |

## 3. LINE のボットを作成する

1. **LINE** アダプターでボットを作成し、チャネルシークレットとチャネルアクセストークンを入力します。
2. LangBot の Webhook コールバック URL をチャネルの **Webhook URL** に貼って検証し、**Webhook の利用** をオンにします。

## 4. 紐付けてテストする

ボットを開いて作成したパイプラインを選び、保存してボットが有効になっていることを確認します。

QR コードで公式アカウントを友だち追加し、メッセージを送ります。

## トラブルシューティング

- 同じホストの Docker でセルフホスト版 Dify を動かす場合は、両方を共通の Docker ネットワークに参加させ、`localhost` ではなくコンテナのアドレス（例：`http://dify-nginx/v1`）を使います。
- Chatflow アプリが返すのは回答（Answer）ノードの出力だけです。
- Webhook の検証に失敗する場合は、URL と、インターネットから HTTPS で到達できるかを確認します。
- 返信がない場合は、LINE Official Account Manager の応答メッセージをオフにし、ボットの代わりに自動応答しないようにします。
- WebUI の **モニタリング** に、すべてのメッセージ、パイプラインの実行、エラーが記録されます。

## よくある質問

### LINE には公開 IP のあるサーバーが必要ですか？

必要です。または LangBot Cloud を使えます。LINE は Webhook を呼び出すため、LangBot には公開 HTTPS URL が必要です。LangBot Cloud にはドメインと HTTPS があります。

### LINE のボットはストリーミング返信に対応していますか？

対応状況は[プラットフォーム機能一覧](/ja/insight/platform-features)で確認してください。AI 側の生成が終わってから返信が送られます。

### 同じ Dify の設定を他のプラットフォームでも使えますか？

はい。1 つのパイプラインを複数のボットに紐付けられるので、同じ設定で複数のプラットフォームに同時に応答できます。
