---
title: "システムコマンド"
---

ボットの接頭辞（既定値 `/`）を使います。`/reset` は `/new` の別名です。有効なシステムコマンドは同名のプラグインコマンドより優先されます。

`/undo` は LocalAgent のチャット履歴から最後のやり取りを削除します。`/retry` はテキストの応答を再生成しますが、プラットフォームに表示済みのメッセージは削除しません。他のプロセッサは非対応であることを通知します。`/model` の変更は現在のセッションにのみ適用され、`/new` で既定のモデルに戻ります。

コマンドごとに（プラグインも含めて）`everyone` または `admins` を選べます。`/whoami` で送信者 ID（例：`person_10001`）を調べてセッション監視で管理者に設定してください。リストが空なら管理者はいません。権限がない場合、`silent` は通常のルーティングを続け、`notice` は権限不足を通知します。

| コマンド | システムコマンド | 既定で有効 | 権限 |
|---|---|---|---|
| `/help` | 利用可能なコマンドを表示 | ✓ | everyone |
| `/new` | 新しい会話を開始 | ✓ | everyone |
| `/stop` | 現在の応答を停止 | ✓ | everyone |
| `/retry` | 直前の応答を再生成 | ✓ | everyone |
| `/undo` | 最後のやり取りを削除 | ✓ | everyone |
| `/whoami` | 送信者とセッションの ID を表示 | ✓ | everyone |
| `/status` | セッションの状態を表示 | ✓ | admins |
| `/usage` | セッションの使用量を表示 | ✓ | admins |
| `/model` | セッションのモデルを表示・変更 | — | admins |
| `/tools` | 利用可能なツールを表示 | ✓ | admins |
| `/plugins` | 有効なプラグインを表示 | ✓ | admins |
| `/version` | LangBot のバージョンを表示 | ✓ | admins |
