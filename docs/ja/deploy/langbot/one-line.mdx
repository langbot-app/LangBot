<Info>
Windows・macOS・Linux で LangBot をセルフホストする推奨方法です。セルフホストしない場合は [LangBot Cloud](https://cloud.langbot.app) をご利用ください。
</Info>

## インストール

macOS / Linux：

```bash
curl -fsSL https://langbot.app/install.sh | bash
```

Windows（PowerShell）：

```powershell
irm https://langbot.app/install.ps1 | iex
```

スクリプトは [lbctl](https://github.com/langbot-app/langbot-cli)（LangBot CLI）をインストールし、lbctl が LangBot をデプロイします。

- **ネイティブ（デフォルト・推奨）**：Python を自動でダウンロード・設定します。事前準備も管理者権限も不要です。
- **Docker**：Docker がある場合に選択でき、`--driver docker` で指定もできます。
- 起動／ログイン時の自動起動が有効になり、最後に「LangBot is ready」パネルが表示されます。

完了後 `http://localhost:5300` を開き、管理者アカウントを作成してください。

## 日常の管理

```bash
lbctl status              # 状態とバージョン
lbctl logs                # ログ
lbctl stop / start / restart
lbctl upgrade --yes       # 最新の LangBot へアップグレード
lbctl update              # lbctl 自体を更新
lbctl autostart disable   # 自動起動を無効化
lbctl uninstall           # アンインストール（データは既定で保持）
lbctl list                # ローカルの全インスタンス
```
