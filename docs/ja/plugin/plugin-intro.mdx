LangBotは、大規模言語モデルツール、コマンド、メッセージングプラットフォームアダプター、LLMリクエスターなど、さまざまな内部コンポーネントで構成されています。拡張性と柔軟性の要件を満たすために、本番環境グレードのプラグインシステムを実装しました。

プラグインは Plugin Runtime により統一して管理されます。多くのプラグインは専用ランタイムを使用し、正確な artifact の有効な署名が確認されたリリースのみ、LangBot Cloud で[ワークスペース間の共有資格](/ja/plugin/certified-plugins)を得られます。レビューだけでは認証になりません。

<img width="600" src="/images/zh/plugin/dev/plugin_system_arch.png" />

## プラグイン構造

プラグインは、特定の機能に基づいて次のコンポーネントを提供できます:

- イベントハンドラー: パイプライン実行中のイベントをリッスンし、コンテキストやパイプラインを変更します。
- コマンド: `!`(または他の設定されたプレフィックス)で始まるユーザーコマンドメッセージによってトリガーされます。
- ツール: LangBotの組み込みLocal Agentの実行中にLLMによって呼び出されます。
- RAGエンジン: ナレッジベースのドキュメントインデックス作成と検索を管理します。

将来的には、プラグイン実装のためにより多くのコンポーネントタイプがサポートされます。

## プラグインのインストール

現在、プラグインパッケージのアップロード、プラグインマーケットプレイスからのインストール、および GitHub Release からのインストールをサポートしています。
LangBotのプラグイン管理ページで、右上隅をクリックしてインストール方法を選択します。

<img width="600" src="/images/zh/plugin/install_method.png" />

`Upload Local`をクリックして、他の人が共有した`.lbpkg`ファイルまたはマーケットプレイスからダウンロードしたファイルを選択してプラグインをインストールします。ローカルアップロードまたは GitHub からのインストール時に、プラグインが宣言した LangBot の対応範囲が現在のバージョンと互換性がない（または宣言が無効な）場合、互換性の警告が表示され、明示的に確認するまでインストールできません。

または、プラグインマーケットプレイスタブをクリックし、プラグインを選択してインストールをクリックします。マーケットプレイスには現在の LangBot バージョンと互換性のあるバージョンが少なくとも 1 つ存在するプラグインのみが表示され、インストール時には最新の互換バージョン（安定版優先）が自動的に選択されます。

<img width="600" src="/images/zh/plugin/install_from_marketplace.png" />

プラグインをインストールした後、パイプライン設定ページでプラグインを選択する必要があります。

<img width="600" src="/images/zh/plugin/pipeline_extensions.png" />

## プラグイン管理

### プラグイン設定

一部のプラグインでは、特定の設定項目を入力する必要がある場合があります(プラグインREADMEの指示を参照)。プラグインカードをクリックしてプラグイン詳細ページに入り、プロンプトに従って必要な情報を取得して入力します。

<img width="600" src="/images/zh/plugin/plugin_config.png" />

### プラグインの更新

プラグインマーケットプレイスからインストールされたプラグインのみを更新できます。プラグイン詳細ページのタイトル横にインストール済みのバージョンが表示され、マーケットプレイスに互換性のある新しいバージョンがある場合は詳細ページ右上に「vX.Y.Z に更新」ボタンが表示されます。インストール済み一覧のプラグインメニューからも更新できます（非互換の新バージョンでは更新通知は表示されません）。

<img width="600" src="/images/zh/plugin/update_plugin.png" />

LangBot 本体のアップグレード後にインストール済みプラグインが非互換となった場合でも、警告が表示されるのみで、プラグインが自動的に無効化されることはありません。

## プラグインマーケットプレイス

プラグインマーケットプレイスには、LangBotの内部`プラグイン管理`ページからアクセスするか、スタンドアロンサイト[LangBotプラグインマーケットプレイス](https://space.langbot.app/market)にアクセスできます。
