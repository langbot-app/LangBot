# HumanTakeover(人工接管)

[English](../README.md) | [日本語](README_ja_JP.md)

一款用于 LangBot 的人工接管与人工回复插件。支持人工通过内置 Web 控制台接管任意私聊或群聊会话,阻断 AI 自动回复,并以文本、图片、语音、文件的形式人工回复。

## 功能特性

- **接管即阻断 AI**:会话被接管后,AI 流水线被中止(`prevent_default`),由人工处理。
- **Web 控制台(单 Page 组件)**:双栏布局 + 右侧可折叠信息面板,遵循 LangBot 设计语言,适配明暗主题。
- **全部会话**:列出所有私聊与群聊;群聊消息区分发言用户。
- **人工回复**:控制台内可发送纯文本、图片(base64)、语音(base64)、文件(base64)。
- **复制与引用**:每条消息提供复制、引用操作;引用会在下一条回复中加入标准 `Quote` 组件。
- **撤回与防撤回**:可撤回自己发送的消息(走平台标准 `delete_message`);当对方删除已保留的消息时,控制台将其标记为「已撤回」而非直接丢失。
- **语音/图片渲染**:语音消息内联播放,图片内联展示。
- **游标历史**:消息按 `before_ts` 游标分页加载,长历史以有界响应逐页拉取,避免一次性大响应冻结界面;300 条 / 8 MiB 的保留策略保持不变。
- **草稿按会话保存**:输入框内容与已选中的图片/文件只属于当前会话;切换会话时保存并恢复,人工回复只会带上该会话自己选择的附件。
- **10 分钟自动取消接管**:接管后若在配置时长内无人工响应则自动取消;人工静默期间显示倒计时,人工回复即重置计时。
- **触发词**:当用户消息包含配置的触发词时,会话被标记为未处理(头像上出现微信式红点),弹出提醒,并(可选)自动接管。
- **用户标签**:在 Profile card 为用户打标签;控制台按标签过滤会话、列出已打标签用户,并在用户/群卡片展示标签。标签按用户维度持久化。
- **信息卡片**:点击用户/群头像查看可获取到的信息(ID、用户名、备注、来源 IM、头像、Bot、适配器)。
- **图传插件接口**:可选配置上传地址,控制台可将已选图片交给图传插件并改用其返回的稳定 URL 发送。
- **数据持久化**:会话与消息通过 LangBot `plugin_storage`(数据库支撑)存储,重启不丢失。
- **清理存储**:一键清空所有存储数据(带自定义二次确认弹层)。
- **国际化**:完整的简体中文 / 英文界面。

## 配置项

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `takeover_timeout` | integer | 600 | 接管后若该秒数内无人工响应则自动取消接管。 |
| `trigger_words` | array[string] | `[]` | 用户消息包含任一触发词时标记未处理并自动接管。 |
| `auto_takeover_on_trigger` | boolean | true | 命中触发词时是否自动接管。 |
| `max_labels_per_user` | integer | 10 | 单个用户可添加的标签数量上限。 |
| `label_colors` | array[string] | 八种默认色 | 未指定颜色时标签循环使用的调色板(最多 8 项)。 |
| `image_plugin_upload_url` | string | `""` | 可选的图传插件上传地址;留空则控制台不显示上传按钮。 |

## 权限声明

`manifest.yaml` 声明了插件实际使用的最小能力:`storage.plugin`(插件私有存储)、`bot.read`(查询 Bot)、`bot.message.send`(人工回复)、`bot.platform_api`(撤回使用的标准 `delete_message`)。声明后插件从兼容模式进入严格模式:既有安装不受影响,全新安装或升级时会请求 Workspace 成员确认后启用。

## 用户标签

标签挂在用户维度(以平台用户 ID 标识),持久化在 installation 作用域的 `ht_user_labels_v2` 行中,因此同一用户的标签可跨会话复用,无需复制进每条会话记录。控制台支持为用户增、删、改标签、列出全部已打标签用户、按标签过滤会话列表,并在用户/群卡片展示标签。损坏的标签数据会降级为「无标签」,不影响消息功能。

## 图传插件接口

将 `image_plugin_upload_url` 配置为图传插件的 HTTP 端点(例如 StickerHub 的 Page `/add`)。上传时控制台 POST `{"name": ..., "data_url": ...}`(同时携带 `image_base64` 兼容其他图传插件),并期望返回包含稳定 `url` 的 JSON(如 StickerHub 返回 `{"name", "url", ...}`)。控制台在发送前用该 URL 替换本地 data URL,人工回复与 AI 回复均可复用。SDK 级契约为 StickerHub 的 `stickerhub_get_sticker_url` Tool(在 Runner 执行上下文内可用,需要 `plugin_tools` 能力)。


## 使用方法

1. 在 LangBot 中安装并启用插件,按上表配置参数。
2. 从 WebUI 侧边栏打开 **人工接管** 页面。
3. 选择会话,点击 **接管** 阻断 AI,然后人工回复。
4. 点击头像查看用户/群信息;点击 **清理存储** 重置数据。

## 组件

- **EventListener(事件监听器)**:记录消息、缓存适配器、匹配触发词,并在接管期间阻断 AI。
- **Page(`console`)**:Web 管理控制台(`index.html` + `console.py`)。
