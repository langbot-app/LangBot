这些问题的答案通常分散在产品手册、销售政策、实施流程、员工制度和会议纪要中。现在，你不必逐份查找文档，直接在微信里向 LangBot 知识库提问即可。

![企业微信客服知识库问答效果](/images/articles/wecom-customer-service.jpg)

## 知识库里有什么

当前 LangBot 知识库汇集了企业日常使用的多类资料，包括：

- 客户案例：记录不同行业、团队规模、使用平台和方案选择
- 产品手册：介绍产品功能、版本区别、适用人数和部署方式
- 销售政策：包含标准价格、活动规则和适用条件
- 实施流程：说明签约交接、实施周期、测试和上线要求
- 故障处理手册：提供问题分级、排查顺序和处理方法
- 报销标准与员工制度：包含差旅住宿、交通、请假和费用报销规则
- 会议纪要：记录产品计划、功能调整和最新业务信息

知识库支持导入 **PDF、Word、Markdown** 等多种常用文档格式。不同部门可以直接使用已有资料建立知识库，不必把所有内容重新整理成固定问答。

![LangBot 企业知识库配置](/images/articles/wecom-knowledge-base-config.png)

## 像聊天一样查询企业资料

打开企业微信客服后，直接说出你想知道的事情。你不需要记住文件名，也不需要使用固定格式。

可以这样问：

- 200 人的公司应该购买哪个版本？
- 企业微信最低需要哪个版本？
- 学校客户 9 月购买专业版，可以享受 88 折吗？
- 客户昨天刚签合同，今天应该做什么？
- 机器人突然不回复，应该先检查什么？
- 去杭州出差，酒店最多可以报销多少？
- 企业微信新版文件解析什么时候上线？

LangBot 知识库会从相关资料中寻找依据，再把答案整理成容易理解的回复。

## 一个问题可以包含多个条件

你也可以把完整需求一次说清楚。例如：

> 我们有一个 260 人的教育客户，希望使用飞书，9 月份上线，还希望参加本月优惠。应该推荐哪个版本？有哪些风险？

面对这类问题，LangBot 知识库会同时参考产品版本、人数限制、行业政策、活动规则和类似客户案例，而不是只回答其中一个条件。

如果客户还要求数据本地存储，也可以继续追问：

> 客户要求数据必须保存在本地，版本选择会发生变化吗？

LangBot 知识库会结合私有化部署要求给出补充说明。

## 查询产品和价格

你可以询问产品能力、版本区别、适用人数和标准价格：

- 基础版、专业版和企业版有什么区别？
- 专业版最多支持多少人？
- 哪个版本支持 API？
- 哪个版本支持私有化部署？
- 专业版的标准价格是多少？

## 查询交付和故障处理

LangBot 知识库也可以根据实施流程和故障处理手册回答：

- SaaS 标准实施通常需要几个工作日？
- 正式上线前至少需要完成哪些测试？
- 知识库准确率只有 82%，建议上线吗？
- 单一客户完全不可用属于什么故障级别？
- API 连续失败几次后需要升级？

## 查询公司制度和最新消息

除了产品资料，你还可以查询员工制度和会议决定：

- 去上海出差的住宿标准是多少？
- 出差结束后多久需要提交报销？
- 某项功能的最新上线日期是什么时候？

当正式手册和最新会议纪要涉及同一件事时，LangBot 知识库会结合更新后的信息回答，帮助你减少使用旧资料的情况。

## 在 LangBot Cloud 部署企业微信客服知识库

LangBot Cloud 会托管运行环境，并提供企业微信回调所需的公网域名和 HTTPS。开始前请准备：

- 已完成企业认证并开通[微信客服](https://kf.weixin.qq.com/kf)的企业微信账号
- 用于问答的 PDF、Word 或 Markdown 文档

### 1. 创建 LangBot Cloud 实例

1. 打开 [LangBot Cloud](https://cloud.langbot.app)，登录 LangBot Account。
2. 为机器人选择一个名称。这个名称也会成为实例的 `.langbot.cloud` 访问地址。
3. 选择支持企业微信客服的套餐，确认价格、资源和消息平台范围后继续。
4. 确认配置并部署。实例通常会在 1 到 2 分钟内完成初始化。
5. 状态变为**运行中**后，点击**打开机器人**进入 LangBot 控制台。

### 2. 配置对话模型和嵌入模型

进入 LangBot 控制台的**模型**页面：

1. Cloud 会提供可直接使用的 LangBot Models 及一定的模型积分；也可以添加自己的模型供应商、Base URL 和 API Key。
2. 选择或添加一个对话模型，用于根据检索结果生成最终回答。
3. 准备一个嵌入模型，用于将文档和问题转换为向量。可以添加供应商提供的 Embedding 模型，也可以选择零配置的 `chroma-内置`。

先在流水线的**对话调试**中确认对话模型能正常回复，再继续创建知识库。

### 3. 创建并填充知识库

进入**知识库**页面，点击**创建知识库**：

1. 填写知识库名称和说明。
2. 选择已安装的 RAG 引擎。不同引擎的参数不同，使用内置方案时按页面提示选择刚才准备的嵌入模型。
3. 设置分块参数；首次使用可以先保留默认值，后续再根据文档结构和检索效果调整。
4. 创建完成后进入知识库的**文档**页面，上传 PDF、Word 或 Markdown 文件。
5. 等待解析和索引完成，确认文档状态正常后再测试问答。

建议先上传少量具有明确答案的资料，并用几个可以从原文核对的问题验证效果。资料中如有过期制度或互相冲突的版本，应先清理或标明生效日期。

### 4. 将知识库绑定到流水线

进入**流水线**页面，编辑默认流水线或创建一条客服专用流水线：

1. 在 **AI 能力**中将运行器选择为**内置 Agent**。
2. 选择已经配置好的对话模型。
3. 在知识库选项中勾选刚创建的知识库。
4. 如已配置 Rerank 模型，可以同时启用重排序并设置 Top-K；这一步是可选的。
5. 保存后进入**对话调试**，提出一个只能从上传文档中找到答案的问题。

回答能够引用文档中的有效信息后，再进行企业微信接入。知识库创建和检索参数的完整说明见[知识库文档](/zh/usage/knowledge/readme)。

### 5. 准备企业微信客服配置

登录[企业微信客服后台](https://kf.weixin.qq.com/kf)：

1. 在**企业信息**中记录企业 ID。
2. 进入**开发配置**并点击**开始使用**。
3. 生成并保存 `Token` 和 `EncodingAESKey`。
4. 暂时保留该页面，稍后需要填写 LangBot 生成的 Webhook URL，并复制企业微信生成的 `Secret`。

`Secret`、`Token` 和 `EncodingAESKey` 都属于敏感信息，不要公开或提交到代码仓库。

### 6. 在 LangBot 创建企业微信客服机器人

进入 LangBot 控制台的**机器人**页面，创建一个**企业微信客服**机器人：

1. 填入企业 ID、`Token` 和 `EncodingAESKey`。
2. 首次保存时 `Secret` 可先填写临时值。
3. 绑定前面配置好的知识库流水线，保存并启用机器人。
4. 从机器人配置页面复制完整的 Webhook 回调地址。Cloud 已经为 `.langbot.cloud` 地址配置好公网 HTTPS，无需替换域名。

回到企业微信客服后台，将该 URL 填入开发配置并保存。验证成功后，复制企业微信页面生成的 `Secret`，再回到 LangBot 用真实 `Secret` 替换临时值并保存。

### 7. 创建客服账号并验收

在企业微信客服后台进入**客服账号**，创建一个客服账号并获取对外服务入口。使用普通微信打开该入口，发送一个知识库测试问题。

如果能够收到依据上传文档生成的回答，说明企业微信回调、客服机器人、流水线和知识库均已连通。如果企业微信无法保存回调 URL，请优先检查 Webhook 地址以及两端的 `Token` 和 `EncodingAESKey` 是否一致。更多字段截图见[企业微信客服接入文档](/zh/usage/platforms/wecom/wecomcs)。如有私有部署要求，再参考 [Docker 部署文档](/zh/deploy/langbot/docker)。
