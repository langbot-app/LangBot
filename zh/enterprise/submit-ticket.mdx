[已订阅，提交工单](https://space.langbot.app/profile?tab=tickets&language=zh)

请使用合同登记的 Space 账号登录，进入个人资料的工单页，选择「企业支持：问题受理」或「企业保障：升级与咨询」。工单入口面向登录用户，企业权益由团队核验合同、登记账号和有效期后确认。订阅编号本身不能证明身份。

## 必填与补充资料

- 订阅/合同编号、企业名称、问题类型和问题概述。
- 缺陷受理：LangBot 版本、部署方式、预期与实际行为、复现步骤、业务影响。
- 相关日志填写脱敏后的片段；没有日志时解释原因。不提交访问令牌、密码、完整聊天记录、客户个人信息或原始配置文件。
- 升级/咨询：登记实例、当前与目标版本（如适用）、咨询目标及可预约时间。
- 资料或文档咨询无需编造日志和复现步骤，可使用升级与咨询入口说明需求；技术咨询额度仅适用于保障计划。

表单只收集文本信息，不会自动采集实例数据或生成诊断包。图片只用于必要的已脱敏截图。安全漏洞详情请勿直接提交到公开 GitHub issue。

## 后续处理

团队先核验订阅，再确认范围并分诊。可以是文档指引、索取补充资料、预约保障档咨询、确认公开 Core 缺陷，或说明不在服务范围。自动通知邮件不算首次人工响应。

经确认的通用缺陷只将必要且脱敏的复现信息提交公共维护流程；客户合同、日志和业务信息不自动同步到公开 GitHub。请在原工单补充资料，避免多渠道重复提交。
