[前往 LangBot Space 提交工单 →](https://space.langbot.app/profile?tab=tickets&language=zh)
</Tip>

## 提交步骤

1. 使用合同中登记的 Space 账号登录。
2. 进入「个人资料 → 工单」，选择模板：
   - **企业支持：问题受理**：报告 LangBot Core 的疑似缺陷
   - **企业支持：升级与咨询**：升级兼容性问题、技术咨询预约（保障计划）、文档与采购资料
3. 填写订阅/合同编号和企业名称，然后按表单填写问题信息。

团队会先核对合同、登记账号和服务期限，再确认权益。仅凭订阅编号不能证明身份。

## 需要准备的信息

**问题受理**

- LangBot 版本与部署方式
- 预期行为与实际行为
- 复现步骤
- 脱敏后的相关日志（没有日志请说明原因）
- 业务影响

**升级与咨询**

- 登记实例及当前版本、目标版本（如适用）
- 咨询目标与背景
- 希望沟通的时间（如需预约）

<Warning>
请勿提交访问令牌、密码、完整聊天记录、客户个人信息或原始配置文件。截图请先脱敏。安全漏洞请不要发布到公开的 GitHub issue。
</Warning>

## 提交之后

团队核验订阅后进行分诊，可能会：

- 给出文档指引或请您补充资料
- 预约技术咨询（保障计划）
- 确认为 LangBot Core 缺陷，进入公共维护流程
- 说明问题不在服务范围内

确认的通用缺陷只会把必要且已脱敏的复现信息提交到公共维护流程，合同、日志和业务信息不会同步到公开 GitHub。补充资料请回复原工单，不要通过多个渠道重复提交。
