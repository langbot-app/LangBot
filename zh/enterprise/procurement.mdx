1. 通过邮件联系，说明企业名称、拟订阅档位与使用情况。
2. 确认支持范围、税费与发票事项，签订年度服务合同。
3. 按合同完成付款，登记联系人、Space 账号及服务期限。
4. 收到订阅证书与服务说明，通过 Space 提交支持请求。

## 合同与开票

签约主体：**北京浪波智能科技有限公司**。

合同标的：**LangBot 开源软件年度维护、版本信息与技术支持服务**。

价格按签约企业收取年费，不按员工人数计费。税费、发票类别与服务期限以正式报价和合同为准；发票内容由财务根据可开票范围确认，不开具虚假的软件商用授权费或捐赠凭证。

## 开通交付

- 服务订单与合同、服务期限和指定联系人。
- 年度企业支持订阅证书，注明其证明支持服务关系，不构成额外软件授权。
- 版本化的服务范围与响应说明、Space 工单入口与账号登记。
- 如为保障计划，登记 1 个生产实例以及技术咨询额度。
- 官网支持者名称展示须单独授权，可选择匿名。

履约期间保存季度公开维护摘要、工单记录和咨询记录；保障计划另提供年度版本、依赖与安全状态说明。服务说明页面后续变更不自动修改存量合同权益。

## 续费与支持关系

续费另行确认，不默认自动扣款。服务开始、结束、取消或退款安排以合同为准。订阅到期不会限制 Apache 2.0 许可下的软件使用。Cloud 算力、模型额度与托管服务不包含在本订阅内。

联系时提供企业名称、意向档位和使用概况即可，合同签署前再按需补充开票资料；不要通过公开工单或 GitHub 发布银行和税务资料。
